# Authentication

This site requires no authentication. All content is publicly accessible.

## Static API

All endpoints under `/api/` are open JSON files served without authentication.

## MCP Tools

The MCP endpoint at `https://tools.moddable.games/mcp` requires no API key or authentication. All 83 tools are freely callable.

## REST API

The REST API at `https://tools.moddable.games/api/call` requires no authentication.

## Rate Limits

No rate limits are enforced. Please be reasonable with request volume.
