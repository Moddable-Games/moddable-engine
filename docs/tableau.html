Cards, Tiles and Dice

One plugin plays every component game: the 52-card deck, the Bavarian 32, Flower 48, double-six dominoes, mahjong and standard dice. A game names its shape of play in frontmatter as game:.

Shapes of play

Each shape is a mechanic in packages/plugins/tableau/src/mechanics/, chosen by name:

war, climbing, trick-taking, shedding, dominoes, scorecard, press-your-luck, trains, branching, patience, laying, knocking, partnership-melds, lone-declarer, called-partner, pegging, bluffing, rolling-rounds, house, shooting, holdem, fishing, tableaus and wall.

Hidden hands

Each seat sees only what it may: the plugin projects the state for a seat (projectForSeat), and the AI decides from that view alone. A hidden-information game is not searched, because a search would play out futures holding the other seats' cards.

Families

52-card deck, Bavarian 32, Flower 48, Dominoes, Mahjong and Dice.
